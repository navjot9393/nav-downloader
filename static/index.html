Connect to JDownloader

  1. Turn on JDownloader's local API, using any one of these:
    In JDownloader's settings (My.JDownloader or its own window)

    Settings → Advanced Settings → search DeprecatedApi. Tick RemoteAPI: Deprecated Api Enabled, leave Deprecated Api Localhost Only ticked, then restart JDownloader.

    With one command

    Stop JDownloader, run this with your JDownloader config folder, then start JDownloader:

    By hand

    Stop JDownloader. In its cfg folder, open org.jdownloader.api.RemoteAPIConfig.json and set:

    "deprecatedapienabled": true, "deprecatedapilocalhostonly": true, "deprecatedapiport": 3128

    Then start JDownloader.

  2. Share JDownloader's network. The API only answers on JDownloader's own localhost, so Nav Downloader has to run inside JDownloader's network: in Docker Compose network_mode: service:jdownloader, or docker run --network container:jdownloader. Publish Nav Downloader's port on the JDownloader container.
